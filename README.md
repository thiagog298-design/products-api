# Products API

This project is a simple **REST API** built with **Java Spring Boot**.  
It was created to practice backend development and demonstrates how to manage products with basic CRUD operations.

## Features
- Create, read, update and delete products
- RESTful endpoints
- Organized project structure with Gradle

## How to run
1. Clone this repository  
2. Run the project with `./gradlew bootRun`  
3. Access `http://localhost:8081/products`
